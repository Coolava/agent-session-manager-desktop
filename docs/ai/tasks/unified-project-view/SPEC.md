## 이번 구현의 적용 기준

- Claude 원본 그룹은 계정/조직+그룹 ID, Codex 원본 배정은 환경/호스트+출처+배정 종류+프로젝트 ID를 기준으로 한다. 이름만 같은 명시적 배정은 합치지 않는다. 기존 원본 식별 범위를 유지한다.
- Codex의 원본 명시 배정과 경로 추정을 구별한다. 참조가 사라지거나 지원하지 않는 종류의 명시 배정도 다른 배정에 합치지 않는다. 원본 배정 정보가 불완전한 항목에는 미배정 세션을 자동으로 넣지 않는다.
- 루트는 기존 origin cwd / Codex 대표 projectCwd를 사용한다. Windows 로컬 드라이브/UNC 경로는 대소문자·구분자·끝 구분자·점 경로를 정규화한다. POSIX/SSH 경로는 대소문자와 호스트를 보존한다. 상하위 폴더라는 이유만으로 루트를 같다고 보지 않는다.
- 원본 명시 배정/Claude 부모 상속과 기존 scratch·프로젝트 미지정의 ‘이 컴퓨터’ 분류는 보존한다. 동일한 명시적 프로젝트의 worktree는 기존 대표 루트를 따른다.
- 현재 원본 그룹/프로젝트 영역을 유지하며, 미배정 루트는 PROJECT FOLDERS에 표시한다. 통합 프로젝트명 검색과 세션 상세의 통합 프로젝트 표시를 제공한다. 원래 경로와 원래 앱으로 열기는 보존한다.
- 원본 저장 데이터와 기존 GROUPS 편집 기능은 변경하지 않는다.

## 범위 밖

- 영구적인 수동 프로젝트 연결/제외 UI, 원본 앱의 그룹 편집, 서로 다른 제공자의 명시 배정을 같은 프로젝트라고 수동 지정하는 기능.
- 모든 보조 루트의 교차 제공자 연결, 실제 Git/symlink 조회, 프로젝트 ID 통합 저장소 또는 사이드바 전체 재설계.

근거와 초기 제안의 이력은 WORKING-SPEC에 보존하고, 구현·검증 결과는 [HANDOFF.md](HANDOFF.md)에 둔다.
