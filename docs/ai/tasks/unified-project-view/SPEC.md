## 보존할 기존 기준

- 원본 세션의 ID·출처·계정은 보존한다. 수동 GROUPS와 Claude·Codex 원본 그룹/프로젝트를 구별한다.
- 루트는 기존 origin cwd / Codex 대표 projectCwd를 사용한다. Windows 로컬 드라이브/UNC 경로는 대소문자·구분자·끝 구분자·점 경로를 정규화한다. POSIX/SSH 경로는 대소문자와 호스트를 보존한다. 상하위 폴더라는 이유만으로 루트를 같다고 보지 않는다.
- 원본 명시 배정 정보와 기존 scratch·프로젝트 미지정의 ‘이 컴퓨터’ 분류는 보존한다. 동일한 명시적 프로젝트의 worktree는 기존 대표 루트를 따른다. 부모 상속에는 아래 수동 배정 제외 기준을 적용한다.
- 통합 프로젝트명 검색과 세션 상세의 통합 프로젝트 표시를 유지한다. 원래 경로와 원래 앱으로 열기는 보존한다.
- 원본 앱 저장 데이터는 변경하지 않고 기존 그룹 CRUD를 유지한다. Desktop 사용자 그룹 저장은 R-023에 따라 확장한다.

## 이번 구현의 적용 기준

- 같은 환경·호스트에서 정규화한 동일 루트와 앞뒤 공백을 제거한 정확한 원본 이름이 일치하며 제공자별 대상이 각각 하나이면 통합한다. 대소문자·철자 유사성으로 이름을 추정하지 않는다. 같은 제공자/계정의 동명 대상이 경합하면 기존 분리를 유지한다.
- 통합은 일치한 루트에 한정하며 해당 원본 그룹의 다른 경로 세션까지 전이 통합하지 않는다.
- 수동 배정된 세션은 자동 분류 근거 수집에서도 제외한다. 미배정 자식은 수동 배정된 부모를 분류 근거로 상속하지 않는다. 필터의 트리 문맥상 필요한 부모는 ‘문맥 표시’로 보여주고 실제 자동 소속에서 제외한다.
- 통합·원본·폴더 자동 항목은 Groups 한 목록, 사용자 항목은 위쪽 My Groups에 표시한다. 같은 이름의 항목에는 출처/경로 힌트를 표시한다.
- 자동 루트에 유일한 대상이 있으면 그 루트의 나머지 미배정 세션을 함께 표시한다. 서로 다른 이름이나 경합하는 배정이 있으면 그 배정들과 미배정 루트를 분리한다. 지원하지 않는 원본 배정은 근거 없이 다른 배정에 연결하지 않는다.
- 수동 그룹 조회 실패 시 자동 분류를 중지하고 마지막 성공한 수동 그룹과 전체·제공자별 목록을 유지한다. 원본 저장 정보는 변경하지 않는다.
