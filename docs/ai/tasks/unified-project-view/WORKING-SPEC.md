## 제안 검증 사례 — 테스트 구현 없음

- ALT Test: 동일 루트의 Claude 5개/Codex 18개를 자동 통합한다. 단, 명시적으로 다른 그룹·프로젝트 배정이 있는 세션은 R-012에 따라 분리한다. 최종 적용 시 원본 배정과 경로 추정의 출처를 다시 확인한다.
- 다른 경로의 동명 프로젝트: 별도 유지. 같은 원본 ID라도 출처가 다르면 별도 유지.
- 사용자 홈·scratch·프로젝트 미지정의 처리: 기존 보호 규칙을 유지할지는 Proposed다. 확인 없이 R-011의 확정 예외로 추가하지 않는다. 공통 상위 폴더만 같은 경우는 프로젝트 루트가 동일한 경우와 구분한다.
- monorepo와 중첩 프로젝트: 상위 경로 포함만으로 연결하지 않는다.
- worktree·여러 루트: 검증된 원본 소속 또는 사용자 확인이 있을 때 통합하고 원래 경로는 보존한다.
- 자식의 독립 배정/사용자 제외: 부모 상속으로 덮어쓰지 않는다.
- 동일 루트의 명시적 A/B 배정: A/B를 분리하고 미배정 세션은 별도 루트 항목으로 묶는다(R-013). 미배정 세션 때문에 A/B가 전이 병합되거나 임의 배정되지 않아야 한다.
- 새로고침·재실행·목록 순서 변경: 같은 입력과 저장된 사용자 연결이면 같은 분류/집계가 나온다.
- 원본 읽기 실패/연결 대상 삭제/원본 배정 변경: 실패와 실제 변경을 구분하고 확인된 연결의 적용 범위를 넓히지 않는다. 그룹 전체 연결의 이후 구성원은 R-008에 동의한 범위에서만 따른다.

- OQ-008 (Decided / source_traceable_normalization): R-011/R-012와 S-005의 구현 범위에 따라 명시 배정 하나이면 같은 루트 미배정을 함께 표시한다(R-014). 구현 시작 전에 이 적용 기준을 사용자에게 설명했다.
- 완전한 무오류를 보장하는 동일성 추론은 어렵다. 제안 목표는 근거 부족 시 병합하지 않고, 판단 근거와 적용 범위를 설명하며, 사용자 수정이 재발 방지에 반영되도록 하는 것이다.
- 초기 탐색의 최종 Claude Spec Review는 진행하지 않았다. S-005 이후 구현 스킬로 전환했으며, 이번 변경은 자체 diff 검토와 제품 검증으로 닫는다. 미채택 초기 제안을 추가 요구사항으로 승격하지 않는다. SPEC-INDEX 생성/동기화는 요청되지 않았다.

## 결정 로그

### D-0001: 동일 루트 자동 통합과 명시적 다른 배정 분리

- Status: Decided
- Date: 2026-11-02 (Asia/Seoul)
- Source: S-003
- Related: OQ-002, R-005/R-008의 관련 제안, R-011/R-012
- Decision: 동일 루트는 별도 후보 확인 없이 통합 표시한다. 동일 루트라도 명시적으로 다른 그룹·프로젝트에 지정된 세션들은 분리한다.
- Rationale: 사용자가 반복적인 후보 확인을 없애되 명시적 분류 의도를 보존하도록 지정했다.
- Impact: 기존 코드의 일괄 원본 ID 분리에서 통합 표시 판단을 추가한다. 명시 배정과 경로 추정의 출처를 구별해야 한다. 원본 데이터 수정이나 구현 시작까지 승인한 것으로 해석하지 않는다.
- Supersedes: Codex의 동일 루트 후보 전용 제안. 기존 작업 문서의 당시 결정을 삭제하지 않고 통합 표시에서 달라지는 범위만 기록한다.

### D-0002: 복수 명시 배정과 공존하는 미배정 세션 분리

- Status: Decided
- Date: 2026-11-02 (Asia/Seoul)
- Source: S-004(직전 제안에 대한 승인)
- Related: OQ-005, R-013
- Decision: 같은 루트에 서로 다른 명시 그룹·프로젝트가 여러 개 있으면 미배정 세션끼리 별도 루트 항목으로 묶는다. 특정 그룹에 임의 배정하거나 그 세션들을 매개로 명시적 배정들을 합치지 않는다.
- Rationale: 사용자가 직전의 예외 처리 제안에 동의했다.
- Impact: 같은 루트의 그룹 A, 그룹 B, 미배정 항목이 각각 분리된다. 명시 배정 하나인 경우와 제공자 간 동일성 판단은 이번 승인으로 확정하지 않는다.
