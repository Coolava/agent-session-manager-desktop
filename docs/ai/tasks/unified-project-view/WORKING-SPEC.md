## 제안 검증 사례 — 테스트 구현 없음

- ALT Test: 동일 루트의 Claude 5개/Codex 18개를 자동 통합한다. 단, 명시적으로 다른 그룹·프로젝트 배정이 있는 세션은 R-012에 따라 분리한다. 최종 적용 시 원본 배정과 경로 추정의 출처를 다시 확인한다.
- 다른 경로의 동명 프로젝트: 별도 유지. 같은 원본 ID라도 출처가 다르면 별도 유지.
- 사용자 홈·scratch·프로젝트 미지정의 처리: 기존 보호 규칙을 유지할지는 Proposed다. 확인 없이 R-011의 확정 예외로 추가하지 않는다. 공통 상위 폴더만 같은 경우는 프로젝트 루트가 동일한 경우와 구분한다.
- monorepo와 중첩 프로젝트: 상위 경로 포함만으로 연결하지 않는다.
- worktree·여러 루트: 검증된 원본 소속 또는 사용자 확인이 있을 때 통합하고 원래 경로는 보존한다.
- 자식의 독립 배정/사용자 제외: 부모 상속으로 덮어쓰지 않는다.
- 동일 루트의 명시적 A/B 배정: A/B를 분리하고 미배정 세션은 별도 루트 항목으로 묶는다(R-013). 미배정 세션 때문에 A/B가 전이 병합되거나 임의 배정되지 않아야 한다.
- 새로고침·재실행·목록 순서 변경: 같은 입력과 저장된 사용자 연결이면 같은 분류/집계가 나온다.
- 원본 읽기 실패/연결 대상 삭제/원본 배정 변경: 실패와 실제 변경을 구분하고 확인된 연결의 적용 범위를 넓히지 않는다. 그룹 전체 연결의 이후 구성원은 R-008에 동의한 범위에서만 따른다.
