# 그룹 기능 UX 개선

- 날짜: 2026-11-02 (Asia/Seoul)
- 대상: D:/repos/intellian/Session_Manager_Desktop
- 스킬: software-change-workflow
- 단계: 승인된 전체 계획의 구현·검증 완료

## 요청

1. Auto, Claude, Codex 등으로 나눈 그룹 영역을 Groups 한 목록으로 통일한다.
2. 포함된 세션의 Agent 아이콘을 유지하고, 혼합 그룹에는 Claude와 Codex 아이콘을 반씩 표시한다.
3. 세션과 그룹에 우클릭 그룹 할당 메뉴를 제공한다.
4. 별도 할당 화면에서 사용자 그룹을 선택하고, 필요하면 바로 그룹을 생성한다.
5. 사용자가 지정한 그룹을 자동 분류보다 우선한다.
6. 추가 확인 답변: “기존 그룹 자체를 연결해 새 세션도 계속 분류”. 일회성 일괄 복사가 아니다.

## 성공 기준

- 최신 후속 요청에 따라 사용자 그룹은 WORKSPACE 아래 My Groups, 자동 그룹은 그 아래 Groups에 표시하고 소속 세션으로 아이콘과 수를 계산한다.
- 세션 직접 배정 및 그룹 연결이 저장되고 재시작·새로고침 후 유지된다.
- 연결된 기존 그룹에 새 세션이 들어오면 사용자 그룹에서도 조회된다.
- 연결 해제·삭제 후 기존 분류로 복귀하고 원본 세션은 보존된다.
- 기존 검색, 부모/자식 표시, 상태 조회, 원본 앱 열기를 보존한다.

구체적 정책, 변경 범위, 단계와 검증은 [PLAN.md](PLAN.md)를 따른다.
