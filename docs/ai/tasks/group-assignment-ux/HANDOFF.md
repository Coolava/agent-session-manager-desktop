## 변경 결과

- 모든 사용자/자동 그룹을 이름순 Groups 한 목록으로 표시한다. 실제 세션 소속으로 숫자와 Agent 아이콘을 계산하고, 혼합 아이콘은 왼쪽 Claude/오른쪽 Codex를 반씩 표시한다. 동명 항목은 출처/경로로 구별한다.
- 세션·그룹 우클릭 또는 Shift+F10/메뉴 키로 그룹 할당 창을 연다. 복수 그룹 선택·해제와 즉시 그룹 생성, 현재 직접/연결 소속 안내, 오류 후 재시도를 지원한다.
- 그룹 연결은 이후 세션도 포함한다. 사용자 그룹 간 연결은 합집합이며 자기/순환 연결은 UI와 저장 계층에서 거부한다. 사용자 그룹 화면에서 숨겨진 자동 그룹의 연결도 변경·해제한다.
- 직접 배정 제외 → 기존 자동 분류 → 그룹 연결 → 잔여 자동 목록 순서다. 세션 직접 배정이 자동 그룹 연결보다 우선하며 사용자 그룹마다 중복 세션은 한 번만 센다.
- Desktop 전용 저장 모듈이 기존 v1을 읽고 첫 편집부터 v2로 원자 저장한다. 기존 id/name/members와 새 links를 보존한다. 기존 CRUD도 연결을 유실하지 않는다. 그룹 삭제 시 그 사용자 그룹을 가리키는 연결을 정리한다.
- 원본 세션 ID/경로/계정·호스트, 검색, 트리 문맥, 상태, 원래 앱 열기를 보존했다. 원본 앱 데이터와 공용 Python/Tk는 수정하지 않았다.

## 적용과 제한

- 갱신된 실행 파일을 다시 실행하면 적용된다. 최종 실행 파일의 실제 WebView 창 자체는 조작하지 않았으며 최종 빌드 assets를 Chrome에서 실제 스냅샷으로 검증했다.
- 구버전 Desktop 실행 파일은 v2 그룹 파일을 읽지 못할 수 있다. 이는 승인된 계획에 명시한 제한이다. 신버전은 v1/v2를 읽고 손상 파일을 덮어쓰지 않는다.
- 관련 task-local SPEC의 기존 영역 분리/영구 연결 제외를 최신 승인 규칙으로 대체했다. 새 SPEC-INDEX나 외부 Claude 검토는 추가하지 않았다.
- 미완료 구현 또는 추가 사용자 결정은 없다.

## 후속 수정 — 긴 선택 그룹명 표시

- 요청: 그룹 선택 후 상단 그룹명이 길 때 잘려 보이는 문제.
- 원인: 상단에는 기본 폭의 한 줄 이름 편집 입력칸만 있었다.
- 수정: 사용자 그룹의 전체 이름을 별도 제목으로 표시하고 긴 단어도 줄바꿈한다. 기존 편집 입력칸은 남는 가로 공간을 사용한다. 저장·할당·분류는 변경하지 않았다.
- 검증: 새 회귀 테스트의 제목 부재 실패를 확인한 후 수정했다. 960×640에서 공백 없는 긴 이름의 여러 줄 표시와 가로 넘침 없음, 편집 버튼 표시, 이름 변경 후 제목 갱신을 확인했다. 기존 그룹 CRUD 테스트와 합쳐 2개 통과했다.
- npm run check: 오류 0개, 기존 경고 111개/29개 파일. Windows Desktop 빌드 성공, 실행 파일 갱신. verification/desktop-group-long-name.png를 시각 확인했다. diff --check와 범위 자체 검토 통과.
- 작은 표시 수정으로 직접 구현했으며 이번 변경만 별도 커밋한다. 기존 미추적 backup은 제외한다.
