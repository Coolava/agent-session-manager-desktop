# 부모·하위 세션 표시

- 날짜: 2026-10-30 (Asia/Seoul)
- 스킬: software-change-workflow
- 상태: 사용자가 앞선 표시 제안을 승인하고 구현·빌드를 요청했다.
- 위험: High — 공용 Python 조회 모델의 선택적 필드 추가와 Desktop 목록·검색·폴더 필터 변경. 원본 데이터와 기존 필드·호출 규약은 보존한다.

## 확인 사실

- Claude 원본 메타데이터 `spawnedFrom`에 `sessionId`, `sideSession: true`, `name`이 있다. 현재 활성 하위 세션 11개, 부모 ID 7개, 중첩된 하위 세션도 있다.
- 현재 공용 Session/SessionStore는 이 관계를 전달하지 않는다. Desktop bridge와 Svelte 목록은 세션을 평면으로 취급한다.
- Session_Manager는 Git 저장소가 아니다. Desktop 저장소에서 수정 내역·검증·공용 파일 hash checkpoint를 함께 남긴다.

## Step 1 — 관계 전달부터 화면·빌드까지

사용자가 승인한 UI를 한 단계로 구현하고 검증 후 scoped commit한다.

- 공용 `session_manager/models.py`, `storage.py`: 기본값을 가진 부모 ID·하위 이름 필드를 끝에 추가한다. 명시적 `sideSession: true`만 계층 관계로 전달한다. 관계 형식이 잘못돼도 대화 자체를 버리지 않는다. Tk GUI/실행/그룹 저장은 수정하지 않는다.
- `desktop/bridge.py`: 부모 키를 Claude 제공자+같은 계정/조직+부모 세션 ID로 구성한다. Codex의 내부 subagent 제외 규칙은 유지한다.
- Desktop 전용 순수 목록 helper에서 여러 단계 계층을 구성한다. 누락 부모·자기 참조·순환 관계는 독립 행으로 남기고 ‘부모 대화 확인 불가’를 표시한다.
- Sessions: 기본 접힘, 화살표만 펼치기/접기, 제목·행은 기존 상세/더블클릭 열기. 자식은 자체 제목·작업 경로·상태·시간을 보존하고 하위 이름도 표시한다. 부모 상태와 하위 작업 중 개수는 분리한다.
- 검색: 하위 이름·제목·경로 등의 일치 항목과 조상 문맥을 표시하고 자동 펼친다. 검색 중 수동 접기는 허용하고 검색 변경 시 초기화한다. 부모 자체가 일치하면 현재 범위의 하위도 표시한다.
- 폴더: 조회 가능한 최상위 부모의 작업 위치 기준으로 가족을 필터한다. 자식 전용 경로는 사이드바에서 생략하고 독립 대화가 같은 경로를 쓰면 유지한다. 부모 누락 세션은 자신의 경로로 접근한다.
- GROUPS: 실제 멤버를 필터 기준으로 유지한다. 자식만 멤버면 조상은 문맥으로 포함하고 멤버가 아닌 형제는 넣지 않는다. 그룹 저장 내용은 바꾸지 않는다.
- 정렬: 가족은 자신과 하위의 가장 최근 활동을 기준으로 정렬한다. 하위 작업 중 개수는 실제 상태 관찰에 따르며 부모 상태는 덮어쓰지 않는다.
- 상세: 부모 이동과 부모를 찾을 수 없는 상태를 표시한다. 모든 열기 요청은 선택한 원본 세션 key를 사용한다.

## 검증·완료 기준

- 공용 Python 테스트: 기존 기능 회귀, 관계 전달, 누락/비정상 관계, 파일 보존.
- Desktop Python 테스트: 계정·조직별 부모 키, 실제 SessionStore에서 bridge까지, 열기 유지.
- 순수 계층 테스트: 중첩, 누락·순환·자기 참조, 정렬, 검색 조상 문맥·자동 펼침, 그룹 범위 격리.
- Desktop 브라우저: 접기/펼치기·새로고침 유지, 검색·이름 검색, 부모/자식 상태 분리와 만료, 상세·열기·부모 이동, 고아 세션, 폴더·그룹 필터와 독립 경로 보존, 기본/최소 크기 캡처.
- `npm run check`, `scripts/build-desktop.ps1`, 실제 메타데이터를 사용하는 빌드 화면의 읽기 전용 확인, 캡처 시각 검토, diff 자체 검토와 `git diff --check`.
- commit: `Display Claude child sessions under their parent conversations`. 공용 변경 파일은 Git이 없어 SHA256 checkpoint와 변경 사본으로 추적한다.

## 제한

- Claude의 확인된 side session 관계만 추가한다. Codex 내부 subagent를 새로 노출하지 않는다.
- 명시적 관계 정보 부재 시 제목/폴더 이름으로 관계를 추측하지 않는다.
