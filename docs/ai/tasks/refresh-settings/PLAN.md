# 설정 화면과 자동갱신 표시

- 날짜: 2026-11-02 (Asia/Seoul)
- 스킬: software-change-workflow
- 위험도: Medium. Desktop 단일 화면의 설정·타이머 변경이며 backend 계약은 유지한다.
- 사용자 요청으로 설정 화면·주기·자동갱신 여부 이동과 LED 구현이 승인된 범위다.

## 확인한 사실

- 대상은 `frontend/src/DesktopApp.svelte`다. 타이틀바 체크박스로 자동갱신을 켜고 끄며 주기는 5초로 고정되어 있다.
- snapshot 성공 후 Claude/Codex 상태를 독립 조회한다. 목록, 그룹, 상태 조회 오류와 snapshot 경고를 이미 보관한다.
- 새로고침 버튼은 검색 오른쪽, 창 제어 버튼 왼쪽에 있다.
- 기존 Desktop Playwright 회귀 검증과 Windows 빌드 스크립트가 있다.

## 가정과 결정

- 사이드바 설정 메뉴로 설정 화면을 연다. 기존 목록 선택과 검색을 보존하며 돌아올 수 있다.
- 사용 여부와 초 단위 주기는 즉시 적용하고 localStorage에 저장한다. 기본값은 기존과 같은 켜짐/5초다. 입력은 정수 1~3600초로 제한한다.
- LED는 자동갱신을 끄면 숨긴다. 켠 상태에서는 초록색을 유지하고 목록/그룹/제공자 상태 조회 오류 또는 snapshot 경고가 있으면 빨간색이다. 해당 오류가 해소되면 초록색으로 돌아온다. 조회 중에는 깜빡이지 않는다.
- 새로고침 버튼은 현재 위치와 수동 조회를 유지하며 문구를 고정한다.
- 상태 관찰의 기존 15초 만료 정책은 유지한다. 세션 자체의 작업 오류는 조회 실패와 별개다.

## Step 1 — 구현 및 검증

- 제품 범위: DesktopApp.svelte, desktop/README.md. 관련 브라우저 검증과 본 작업 문서만 추가/수정한다.
- 설정 페이지, 설정 저장/복원, 주기 재설정과 타이머 해제, 독립 LED를 구현한다.
- 기존 자동갱신 체크박스 참조 테스트를 설정 페이지 경유로 변경한다.
- 검증: 설정 켜기/끄기와 주기 적용/저장, 타이머 중복 방지, 오류 발생/부분 복구/전체 복구 LED, 새로고침의 고정 문구·수동 동작, 최소 창 크기를 Playwright로 확인한다.
- 전체 Desktop Playwright, npm run check, scripts/build-desktop.ps1, git diff --check를 실행하고 화면 캡처를 확인한다.
- 완료 기준: 위 요구사항 검증 통과와 Windows 실행 파일 빌드. 검증 후 이번 변경만 scoped commit으로 기록한다.

## 위험 및 제외 범위

- 중복 타이머/해제 누락: 가상 시계로 주기 변경과 비활성화를 검증한다.
- 일부 조회만 성공했을 때 잘못 초록색 전환: 제공자별 오류를 합산하고 부분 복구 시나리오를 검증한다.
- 기존 Python/Tk, 공용 Python 모듈, backend API, 원본 터미널 앱, 기존 미추적 백업은 변경하지 않는다.
