# 최종 자체 검토

- 기준: 최종 사용자 지시인 기존 세션 열기. 독립 창 필수 조건은 대체되었다.
- 판정: 현재 로컬 기존 세션 범위에서 전달 가능.

선택 키는 현재 provider 메타데이터에서 다시 찾고 검증된 ID의 앱 URL만 전달한다. 코드/셸 문자열을 실행하지 않는다. UI 자동화와 창 생성 helper를 최종 제품에서 제거했다. URI 전달은 요청으로 표시하고 Desktop 화면 전환 완료를 주장하지 않는다. 실패한 열기를 자동 재시도하지 않는다.

그룹은 별도 파일에 원자적으로 저장하며 계정/provider를 구분한다. 손상된 그룹 파일을 덮어쓰지 않는 테스트를 확인했다. SQLite 연결을 닫고 읽기 전용으로 조회한다. 원본 디자인 토큰/아이콘과 Wails/Svelte를 재사용하며 원본 터미널 초기화를 호출하지 않는다.

Python 9개, 브라우저 7개, Desktop 전용 빌드/Go 검사와 실제 두 앱 URL 전달을 확인했다. 원본 테스트 기준선 실패는 별도로 기록했다. Codex 실시간 상태 미연동, Claude SSH 미실검증, Desktop 업데이트에 따른 URL/메타데이터 변경 가능성은 README/HANDOFF에 명시했다.

새 대화 생성이나 새 창 강제를 구현한 것으로 표시하지 않는다. 기존 Python 프로젝트, 설치 파일, 대화 원본을 수정하지 않았다.
